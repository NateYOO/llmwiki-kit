# wiki-query — 위키에서 근거를 찾아 답하고, 쓰기

먼저 `wiki/index.md`를 읽어 어떤 논문·주제가 있는지 파악한다. `llmwiki`는 macOS/Linux `./llmwiki`, Windows `.\llmwiki.cmd`.
모든 사실 문장에는 근거 꼬리표를 단다: `[근거: <slug> · p.N]`, `[근거: <slug> · Table N]`, `[근거: <slug> · Achievement]`.
검색 결과의 `cite` 값을 그대로 쓰면 된다. 위키에 없으면 **없다고 말하고** `$wiki-ingest`를 제안한다.

## 요청 유형 고르기
| 사용자가 원하는 것 | 모드 |
|---|---|
| 질문에 대한 답, 비교, 요약 | A. 근거 답변 |
| "이 문장/표현이 어디 있었지?" | B. 문구 찾기 |
| "○○ 구조도/그래프/표 찾아줘" | C. 그림·표 찾기 |
| "연구 아이디어", "빈틈", "다음 연구" | D. 아이디어 |
| "drafts/… 이어서 써줘", "문헌고찰 써줘" | E. 이어쓰기 |

## A. 근거 답변
1. `llmwiki search "<핵심어 2–5개>"` (리뷰·주제). 한국어/영어 원어 둘 다 시도한다.
2. 부족하면 `llmwiki search "<핵심어>" --scope source` 로 원문 페이지를 찾는다.
3. 상위 결과의 리뷰 섹션과 source.md 해당 페이지를 **직접 읽고** 답한다. 검색 snippet만 보고 답하지 않는다.
4. 답 형식: 결론 1–2문장 → 근거 bullet(각각 꼬리표) → 한계/불확실성. 논문끼리 다르면 차이를 명시한다.
5. 좋은 답은 위키에 남길 수 있다: "drafts/에 저장할까요?"라고 묻고, 저장하면 `llmwiki index` + `llmwiki log query "<질문>"`.

## B. 문구 찾기
1. `llmwiki find "<문구>"` — 대소문자·줄바꿈·하이픈 차이를 무시한 정확 일치. 결과에 페이지(p.N)가 나온다.
2. 없으면 핵심 단어로 `llmwiki search "<단어들>" --scope source`.
3. 원문을 2문장 이내로 `>` 인용하고 `[근거: <slug> · p.N]`. 비슷한 표현만 찾았으면 "정확히 같은 문장은 없음"이라고 말한다.

## C. 그림·표 찾기
1. `llmwiki figures "<무엇을 그린 그림인지>"` — 그림·표 캡션 검색. 결과에 PNG 경로가 있다.
2. 상위 PNG를 **직접 열어** 요청과 맞는지 확인한다.
3. 답: 그림 번호·페이지·캡션 요약·경로, 그리고 바로 붙여 쓸 수 있는 마크다운
   - drafts/에서: `![Figure 2](../wiki/papers/<slug>/figures/fig2.png)` / 주제 페이지에서: `![…](../papers/<slug>/figures/fig2.png)`
   - "원문 PDF 캡처 · 로컬 연구용"이라 공개 배포 시 저작권(라이선스)을 확인하라고 덧붙인다.

## D. 아이디어 도출
1. 관련 리뷰들의 `## Limitation & Further Study`, `## Originality`, `## Related Papers`를 읽는다 (`llmwiki search "<주제>"`).
2. 아이디어 3–5개: 각 아이디어마다 ① 어떤 빈틈에서 나왔나(근거 꼬리표) ② 연구 질문 ③ 가능한 방법·데이터 ④ 위험. 근거 없는 부분은 `(가설)`.
3. 저장 원하면 `drafts/ideas-YYYY-MM-DD-<주제>.md`에 쓰고(새 파일 생성 전 확인) `llmwiki log draft "<제목>"`.

## E. 이어쓰기 (drafts/)
1. 대상 파일을 끝까지 읽고 문체·구조·이미 인용한 논문을 파악한다. 파일이 없으면 만들지 물어본다.
2. 쓸 내용을 위 A 방식으로 위키에서 찾는다.
3. **덧붙이기만 한다.** 기존 문장은 지우거나 고치지 않는다(고칠 점이 보이면 제안만). 추가 부분 앞에 `<!-- llmwiki: AI 추가 YYYY-MM-DD -->` 주석을 넣는다.
4. 사실 문장마다 꼬리표 + 문단 끝에 리뷰 링크 `[제목](../wiki/papers/<slug>/review.md)`.
5. 끝나면 `llmwiki index` → `llmwiki log draft "<파일 이름> 이어쓰기"`.

## 하지 말 것
- 근거 없는 수치·인용, 위키 밖 기억으로 답하기(필요하면 "위키 밖 일반 지식"이라고 명시).
- source.md 문단 통째 복사, 사용자 글 삭제·수정, 유료 API 사용.
