# LLM 튜터링과 평가 기준 (샘플 주제 노트)

- **학습자 직접 대화형**: [Ruffle&Riley](../papers/2024-schmucker-ruffle-riley-insights-designing/review.md) — 교재에서 스크립트를 자동 생성하고 두 LLM 에이전트가 대화한다. 학습 경험은 좋았지만 단기 학습 성과 차이는 없었다 [근거: 2024-schmucker-ruffle-riley-insights-designing · p.1].
- **사람 튜터 지원형**: [Tutor CoPilot](../papers/2024-wang-tutor-copilot-human-ai-approach/review.md) — 초보 튜터에게 전문가 결정 모델 기반 제안을 주어 RCT에서 숙달률을 4%p 높였다 [근거: 2024-wang-tutor-copilot-human-ai-approach · p.1].
- **평가 기준**: [Yan et al. 2023](../papers/2023-yan-practical-ethical-challenges-large/review.md) — 118편 리뷰에서 낮은 기술 성숙도·재현성 부족을 지적했다 [근거: 2023-yan-practical-ethical-challenges-large · p.10; p.12].
