# projects/ — 내 연구 주제 폴더

연구 주제가 생길 때마다 이 안에 폴더를 하나 만드세요 (예: `projects/AI튜터-설계/`).
- 그 주제의 초안·한글(HWP)·엑셀 같은 자료를 넣어 두는 곳이에요.
- Codex에서는 계속 지식 베이스 폴더(llmwiki)를 열어 두세요. 주제 폴더를 따로 열지 않아요.
- 결과를 이 폴더에 남기려면 요청 끝에: 「결과는 projects/AI튜터-설계/ 에 저장해 주세요」
- 키트는 이 폴더의 기존 파일을 고치거나 지우지 않아요(새 파일만 만들어요). 예외: 「x.md 이어서 써 줘」라고 하면 그 .md 끝에 덧붙이기만 해요.
